Por qué existe

Moki es el alter ego explorador de Jorge Suárez: descubre, se equivoca y construye mundos mientras aprende. Este kit lo convierte en un personaje que cualquiera puede usar para explorar y jugar con IA y videojuegos: en un juego, una página, una app, un wallpaper o un video.

Lo hicimos abierto porque así se aprende mejor: probar pequeño, compartir, volver a intentar. El código es MIT; el arte de Moki va con licencia CC BY-NC 4.0 (da crédito, sin uso comercial).

Úsalo

<!-- Moki camina por tu página. Nivel: nada · poquito · mucho · hardcore -->
<script src="https://moki.jorgesuarez.com.mx/pixel/dist/runtime/moki-pet.js"
        data-juice="poquito" data-hello="¡Hola!"></script>
<script>
  // API: MokiPixel.pet.say('Texto'), .act('celebrate'), .walkTo(400), .emote('idea'), .hide()
</script>
<script type="module">
  import 'https://moki.jorgesuarez.com.mx/pixel/dist/runtime/moki.mjs';
</script>
<moki-sprite clip="play" facing="right" size="64" scale="3"></moki-sprite>
<moki-sprite clip="think" facing="front" emote="dots"></moki-sprite>
// preload
this.load.aseprite('moki', 'moki-64-right.png', 'moki-64-right.json');
// create
this.anims.createFromAseprite('moki');
const moki = this.add.sprite(160, 120, 'moki').play({ key: 'walk', repeat: -1 });
// Vista izquierda = carga moki-64-left (nunca setFlipX: el parche cambiaría de oreja)
# Copia dist/sprites/64/*.png a res://moki/ y dist/engines/godot/*.tres a tu proyecto
var frames = preload("res://moki/moki-64-right.tres")
$AnimatedSprite2D.sprite_frames = frames
$AnimatedSprite2D.play("walk")
# Filtro: Project Settings → Rendering → Textures → Default Texture Filter = Nearest
// 1) Importa moki-64-right.png: Texture Type = Sprite, Filter = Point, Compression = None
// 2) Sprite Mode = Multiple → Sprite Editor → Slice → Grid By Cell Size 64×64
// 3) Copia dist/engines/unity/MokiAtlasImporter.cs a Assets/Editor/
//    Menú Moki → Crear clips desde JSON (usa duraciones y loops del atlas)
// Arrastra dist/strips/64/right/moki_walk_right_strip12.png al IDE:
// GameMaker detecta «_strip12» y lo corta en 12 subimágenes.
sprite_index = spr_moki_walk_right;
image_speed = 1; // 12 fps en la configuración del sprite
{ "format": "9:16", "background": "noche", "duration": 8,
  "timeline": [
    { "at": 0,   "walk_to": 90 },
    { "at": 2.5, "facing": "front", "play": "wave", "say": "¡Hola!" },
    { "at": 4,   "play": "idea", "emote": "idea" },
    { "at": 5.5, "play": "celebrate", "caption": "Prueba pequeño. Aprende rápido." } ] }
# node tools/scene.mjs mi-escena.json --out moki.mp4
# Claude puede escribir el guion: carga la skill claude/skills/moki-pixel
# macOS · Windows · Linux (incluye Omarchy / Hyprland)
# Descarga el instalador en GitHub Releases o corre desde el código:
git clone https://github.com/jorgefsb/moki-pixel && cd moki-pixel/desktop
npm install && npm start
# Conéctalo a Claude Code: los hooks mandan eventos a http://127.0.0.1:47820

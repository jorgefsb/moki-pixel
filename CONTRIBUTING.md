# Contribuir

¡Gracias por jugar con Moki!

1. Abre un issue con la idea de animación o el bug. Si es una animación, di qué intención tiene (curiosidad, logro, reto…) y en qué juego o app la quieres usar.
2. Respeta el canon de [docs/guia-de-personaje.md](docs/guia-de-personaje.md): parche en la oreja derecha, nunca espejar, visor sin rostro.
3. Las animaciones viven en `src/anim/clips.js`. Corre `npm test` y `npm run build`, y adjunta un GIF del clip nuevo en el PR.
4. Código bajo MIT; el arte que generes con el personaje queda bajo CC BY-NC 4.0.
